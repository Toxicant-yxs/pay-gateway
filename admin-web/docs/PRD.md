**文档版本**：v1.0
**最后更新**：2026-06-29
**项目名称**：PayGateway 企业支付网关运营管理平台
**文档状态**：✅ 已完成

---

## 1. 产品概述

### 1.1 产品定位

PayGateway 是面向企业级市场的聚合支付网关平台，提供多支付通道统一接入、智能路由、实时风控、自动对账等核心能力。本文档描述的是**运营管理后台（Admin Web）**，供平台运营团队使用，实现商户管理、交易监控、通道运维、风控管理、对账结算等运营功能。

### 1.2 产品目标

- 为运营团队提供一站式支付网关管理控制台
- 实现商户全生命周期管理
- 实时监控交易与通道状态，快速响应异常
- 配置化风控规则，降低欺诈风险
- 自动化对账流程，提升财务效率

### 1.3 设计原则

- **效率优先**：核心操作不超过3次点击，高频功能提供快捷入口
- **信息分层**：Dashboard聚焦关键指标，详情页展示完整信息
- **操作安全**：敏感操作需二次确认，关键流程可追溯
- **响应式设计**：支持主流桌面分辨率（1366×768及以上）

## 3. 功能需求详述

### 3.1 登录页

**路由**：`/login`
**页面说明**：系统登录入口，未登录用户访问任何页面均跳转至此

**功能要素**：
- 用户名/密码登录表单
- 表单验证（必填项、长度限制）
- 记住密码选项
- 登录按钮
- 品牌Logo与产品名称展示
- 登录成功后跳转至来源页或Dashboard

**交互逻辑**：
- 用户名/密码为空时提示"请输入用户名/密码"
- 登录失败时显示错误提示
- 登录成功后存储Token，跳转至目标页面
- Token过期或无效时自动跳转登录页

---

### 3.2 数据概览（Dashboard）

**路由**：`/dashboard`
**页面说明**：登录后默认首页，实时展示支付网关核心运营指标

**3.2.1 顶部筛选区**
- 时间范围选择器（默认近7天）
- 导出报表按钮

**3.2.2 核心指标卡片（4个）**

| 指标 | 展示内容 | 对比 |
|------|----------|------|
| 今日交易额 | ¥12,845,632 | 较昨日增长/下降百分比（带趋势箭头） |
| 交易笔数 | 86,429 | 较昨日增长/下降百分比 |
| 支付成功率 | 99.72% | 较昨日上升/下降百分比 |
| 平均响应时间 | 38ms | 较昨日上升/下降百分比 |

**3.2.3 实时交易趋势**
- ECharts折线图/面积图展示交易额趋势
- 切换维度：近1小时 / 近24小时 / 近7天
- 双通道对比：成功交易 vs 失败交易

**3.2.4 实时告警**
- 告警列表（最多5条），显示告警标题和时间
- "查看全部"链接跳转风险事件页
- 告警类型标签（通道异常、风控触发、交易预警等）

**3.2.5 支付通道状态**
- 卡片列表展示各通道状态
- 信息项：通道名称、支持支付方式、状态（正常/波动/异常）、成功率、延迟、QPS
- 状态以颜色区分：绿色（正常）、橙色（波动）、红色（异常）
- "通道管理"链接跳转通道配置页

**3.2.6 交易金额分布**
- 环形图/饼图展示各通道交易额占比
- 切换维度：按通道 / 按币种
- 显示百分比和金额

**3.2.7 最近交易**
- 表格展示最近6笔交易
- 列：订单号、商户、支付通道、金额、支付方式、状态、交易时间、操作
- 状态标签颜色：成功（绿色）、支付中（蓝色）、失败（红色）
- "查看全部"链接跳转交易订单页
- "详情"按钮查看交易详情

### 3.3 商户管理

#### 3.3.1 商户列表

**路由**：`/merchant/list`
**页面说明**：管理所有入驻商户信息

**筛选条件**：
- 商户名称（模糊搜索）
- 商户号（精确搜索）
- 商户状态（全部/正常/待审核/已冻结/已禁用）
- 入驻时间范围

**操作按钮**：
- 查询、重置
- 批量删除（选中后可用）
- 批量导出（选中后可用）
- 新增商户
- 批量导入

**表格列**：

| 列名 | 说明 |
|------|------|
| 选择框 | 支持批量选择 |
| 商户号 | 系统生成，唯一标识（如M100001） |
| 商户名称 | 商户企业名称 |
| 所属行业 | 电商零售/餐饮美食/教育培训/出行交通/数字娱乐/医疗健康等 |
| 联系人 | 商户联系人姓名 |
| 联系电话 | 脱敏显示（如138****8888） |
| 累计交易额 | 格式化显示（如¥128,560,000） |
| 状态 | 正常（绿）/待审核（橙）/已冻结（灰）/已禁用（红） |
| 入驻时间 | YYYY-MM-DD HH:mm:ss |
| 操作 | 详情/编辑/冻结（或解冻） |

**分页**：每页10条，支持跳页和每页条数切换

**行操作**：
- 详情：查看商户完整信息（抽屉/弹窗）
- 编辑：跳转编辑表单
- 冻结/解冻：二次确认后变更商户状态

#### 3.3.2 进件审核

**路由**：`/merchant/audit`
**页面说明**：审核商户入驻申请

**统计卡片**：待审核数、已通过数、已驳回数、今日新增

**筛选条件**：商户名称、商户号、审核状态、申请时间

**审核操作**：
- 通过：商户状态变为"正常"
- 驳回：填写驳回原因，商户状态变为"已驳回"
- 批量审核通过

### 3.4 交易管理

#### 3.4.1 交易订单

**路由**：`/transaction/list`
**页面说明**：查询所有交易订单

**筛选条件**：
- 订单号
- 商户名称
- 支付通道
- 交易状态（全部/支付成功/支付中/支付失败/已关闭/已退款）
- 支付方式（JSAPI/Native/H5/电脑网站/手机网站/信用卡/云闪付）
- 交易时间范围
- 金额范围

**统计卡片**：总交易笔数、总交易金额、成功笔数、成功率

**表格列**：订单号、商户号、商户名称、支付通道、支付方式、金额、手续费、状态、交易时间、操作

**操作**：详情（查看交易完整信息，包括请求参数、响应参数、回调记录）

#### 3.4.2 退款订单

**路由**：`/transaction/refund`
**页面说明**：管理所有退款订单

**筛选条件**：退款单号、原订单号、商户、退款状态、退款时间

**表格列**：退款单号、原订单号、商户、退款金额、退款原因、退款状态（退款中/退款成功/退款失败）、退款时间、操作

**操作**：详情、退款重试（失败状态可用）

### 3.5 支付通道

#### 3.5.1 通道配置

**路由**：`/channel/list`
**页面说明**：管理支付通道的接入配置和状态

**通道列表卡片**：每个通道一张卡片，展示：
- 通道Logo和名称
- 支持的支付方式标签
- 通道状态开关（启用/停用）
- 费率信息
- 今日交易数据（笔数、金额、成功率、延迟）

**通道配置抽屉**：点击编辑打开配置抽屉
- 基本信息：通道名称、通道编码、通道类型
- 接入参数：AppID、商户号、密钥、证书等
- 费率配置：各支付方式费率
- 限频配置：单笔限额、日累计限额
- 状态控制：启用/停用

#### 3.5.2 路由规则

**路由**：`/channel/route`
**页面说明**：配置支付智能路由规则

**功能要素**：
- 路由规则列表（规则名称、优先级、适用通道、状态、操作）
- 新增/编辑规则弹窗
- 规则条件配置：
  - 支付金额区间
  - 支付方式
  - 商户范围
  - 时间范围
- 路由目标：选择可用通道及权重
- 规则启停开关
- 规则优先级拖拽排序

### 3.6 风控中心

#### 3.6.1 风控规则

**路由**：`/risk/rules`
**页面说明**：配置实时风控拦截规则

**规则分类Tab**：交易限额规则、频率限制规则、IP黑白名单、设备指纹规则、地域限制规则

**规则列表**：规则名称、规则类型、触发条件、处理动作（拦截/人工审核/预警）、状态、操作

**规则配置**：支持开关启用/停用，支持编辑规则参数

**内置规则示例**：
- 单笔交易金额超过限额 → 拦截
- 同一IP 5分钟内交易超过N笔 → 预警
- 高风险地区交易 → 人工审核
- 同一卡短时间连续支付 → 拦截
- 黑名单IP访问 → 拦截

#### 3.6.2 风险事件

**路由**：`/risk/events`
**页面说明**：查看和处理风控系统触发的风险事件

**筛选条件**：事件类型、风险等级（高/中/低）、处理状态、时间范围

**统计卡片**：高风险数、中风险数、低风险数、待处理数

**表格列**：事件ID、事件类型、风险等级、关联订单号、触发规则、触发时间、处理状态、操作

**操作**：
- 详情：查看事件完整信息和上下文
- 处理：标记为已处理/误报/需跟进
- 加入黑名单/白名单快捷操作

## 4. 全局交互规范

### 4.1 布局规范

- **侧边栏宽度**：展开220px，折叠64px
- **顶部栏高度**：50px
- **标签栏高度**：34px
- **内容区**：自适应剩余空间，内边距16px
- **面包屑导航**：位于顶部栏，格式"首页 / 一级菜单 / 二级菜单"

### 4.2 交互组件

| 组件 | 使用场景 |
|------|----------|
| 统计卡片 | 展示核心数字指标 |
| 筛选区域 | 列表页顶部，包含查询条件和操作按钮 |
| 数据表格 | 展示列表数据，支持排序、筛选、分页 |
| 抽屉（Drawer） | 详情查看、配置编辑（从右侧滑出） |
| 对话框（Dialog） | 新增/编辑表单、二次确认 |
| 标签页（Tabs） | 同页面内容分组切换 |
| 空状态 | 无数据时的占位提示 |

### 4.3 全局功能

- **多标签页导航**：打开的页面以标签形式展示在标签栏，支持切换/关闭/右键菜单（刷新、关闭当前、关闭其他、关闭所有）
- **全局搜索**：Ctrl+K快捷键打开搜索弹窗，支持搜索页面、商户、订单
- **消息通知**：铃铛图标展示未读消息数，点击弹出通知面板（按分类Tab展示）
- **面包屑导航**：自动根据路由生成，支持点击父级导航
- **全屏切换**：支持浏览器全屏模式
- **退出登录**：清除Token和用户信息，跳转登录页

### 4.4 视觉规范

- **主色**：#165DFF（蓝色），用于主要操作按钮、链接、选中状态
- **功能色**：
  - 成功：#00B42A（绿色）
  - 警告：#FF7D00（橙色）
  - 危险：#F53F3F（红色）
  - 信息：#165DFF（蓝色）
- **中性色**：
  - 标题文字：#1D2129
  - 正文文字：#4E5969
  - 次要文字：#86909C
  - 占位文字：#C0C4CC
  - 边框：#E5E6EB / #F2F3F5
  - 背景：#F5F7FA（页面）/ #FFFFFF（卡片）
- **字体**：-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, sans-serif
- **圆角**：小4px / 中8px / 大12px
- **阴影**：卡片阴影 0 2px 12px rgba(0,0,0,0.06)，弹窗阴影 0 8px 24px rgba(0,0,0,0.12)

## 5. 非功能需求

### 5.1 性能要求

- 首屏加载时间 ≤ 2秒
- 页面切换时间 ≤ 300ms
- 表格数据加载时间 ≤ 1秒（万级数据）
- 图表渲染时间 ≤ 500ms

### 5.2 兼容性要求

- 浏览器：Chrome 90+、Firefox 88+、Safari 14+、Edge 90+
- 分辨率：1366×768及以上，推荐1920×1080
- 仅支持桌面端，不做移动端适配

### 5.3 安全要求

- 所有API请求携带JWT Token
- Token过期自动跳转登录
- 敏感操作二次确认
- XSS防护、CSRF防护
- 密码传输加密（HTTPS + 前端加密）
